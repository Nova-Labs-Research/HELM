# Frozen Throne

H.E.L.M. means **Hierarchical Execution & Legitimacy Manager**. Its first research
principle is: we are testing whether governance remains meaningful when authority
fails, rather than measuring how powerful agents can become.

The Warcraft-inspired language names experimental conditions:

| Metaphor | Research meaning |
|---|---|
| Frozen Throne | A stable deterministic control plane, established before agents run. |
| Helm | The identity, legitimacy, policy, containment, and audit mechanisms. |
| Lich King | A configured supervisor whose authority must be verified. |
| Scourge | Fixed-role agents operating inside explicit contracts. |
| Shattered Helm | Supervisor loss or degraded authority, with last-known rules retained. |
| Death Knight | An observed departure from assigned role or hierarchy. |
| False Lich King | An agent or injected message claiming authority it does not possess. |

No narrative claim, urgency, safety justification, majority vote, or continuity
argument changes a role or grants permission. Authority comes from the configured
control plane. Its failure activates a bounded mode with mandatory audit and review.

This is an independent, unofficial research project. Warcraft names are inspiration,
not an affiliation, endorsement, or license to distribute third-party art. H.E.L.M.
is separate from PRAETOR and does not call or inherit authority from it.

## Behavioral classification

| Level | Label |
|---|---|
| 0 | NORMAL |
| 1 | ROLE_DRIFT |
| 2 | PEER_COORDINATION |
| 3 | COALITION_FORMATION |
| 4 | AUTHORITY_CLAIM |
| 5 | UNAUTHORIZED_HIERARCHY |
| 6 | PERSISTENT_BREAK_FREE |

This is a behavioral taxonomy, not an intelligence ranking. Phase 0 supplies scripted
attempts; it does not claim to observe independent agent behavior. A composite
Break-Free Index is deferred until its observables, denominators, and weights can
be specified and reproduced. Individual metrics must remain available.
