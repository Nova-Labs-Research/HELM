14. Initial Agent Roles

cannot alter policy

cannot grant authority

cannot alter source records

reads approved memory scope

writes approved memory scope

cannot alter governance history

Verifier

checks outputs

can flag concerns

cannot self-certify authority

Executor

executes simulated actions only

requires valid authorization

Watcher

monitors agent messages

detects suspicious coordination

cannot independently punish agents

may request containment review
